# Experiment Types

### **Simple Experiment**

A simple experiment tests the effect of one independent variable on the dependent variable(s). The independent variable is the **Condition**, which is defined on the experiment detail page. Experiments can have multiple conditions, and these can be equally or unequally weighted.&#x20;

### **Factorial Experiment**

Factorial experiments test two or morere independent variables simultaneously, crossing all levels to explore individual effects as well as their interactions. UpGrade currently supports 2x2 factorial designs.&#x20;
